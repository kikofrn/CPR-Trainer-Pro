# Public Assets
Place your PDF manuals and video files here to make them accessible to the app.

## Manuals
Ensure these files are in the `public/` folder exactly as named:
- `instructor_manual.pdf` (Used for all courses as the primary teaching guide)
- `student_manual.pdf`
- `pediatric_student_manual.pdf`

## Course Videos
The app expects video files in the following format:

### CPR & AED Course Videos
Pattern: `[##]_EHAcademy - CPR AED Course Video-[SLIDETITLE].mp4`
Examples:
- `01_EHAcademy - CPR AED Course Video-Introduction.mp4`
- `02_EHAcademy - CPR AED Course Video-Why should I learn CPR.mp4`
- `03_EHAcademy - CPR AED Course Video-Heart Attack vs Cardiac Arrest.mp4`
- `04_EHAcademy - CPR AED Course Video-Adult Compressions Technique.mp4`
- `05_EHAcademy - CPR AED Course Video-Rescue Breathing.mp4`
- `06_EHAcademy - CPR AED Course Video-Using an AED.mp4`
- `07_EHAcademy - CPR AED Course Video-Choking Protocols.mp4`
- `08_EHAcademy - CPR AED Course Video-Conclusion & Certification Prep.mp4`

### First Aid Course Videos
Pattern: `[##]_EHAcademy - First Aid Course-[SLIDETITLE].mp4`
Examples:
- `01_EHAcademy - First Aid Course-First Aid Basics.mp4`
- `02_EHAcademy - First Aid Course-Bleeding Control.mp4`
- `03_EHAcademy - First Aid Course-Splinting & Fractures.mp4`
- `04_EHAcademy - First Aid Course-Burn Treatment.mp4`
