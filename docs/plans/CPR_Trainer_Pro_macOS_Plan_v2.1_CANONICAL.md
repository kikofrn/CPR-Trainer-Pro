## 3. Architecture requirements

**Media storage.** Persistent media in `app_data_dir()/media`: created explicitly, actionable UI error if unavailable, never a write inside the bundle. Excluded from Time Machine via the **native URL-resource backup-exclusion API** (`NSURLIsExcludedFromBackupKey` equivalent), validated with `tmutil isexcluded` (or the applicable metadata attribute). No seeding of `public/` into Application Support — immutable fallback assets stay in the Vite bundle; only downloaded or USB-imported media lives in Application Support.

**Media base.** Synchronous constant `media://localhost/`. Remove `get_media_base_path`, backend base-path initialization, and all platform sniffing. Remove the `media.localhost` ATS `exceptionDomain` (mac uses a custom scheme + HTTPS CDN only).

**Protocol handler.** Handle `HEAD` with headers and no body. Range requests: bounded 2 MB chunks (existing behavior preserved). Non-Range requests: **spike FIRST** — test WebKit's response to a bounded initial `206` for video and **record the selected mechanism in DECISIONS.md before continuing the protocol implementation**; images/text/PDFs served only under explicit size caps; **no code path allocates a video-sized buffer**, and PDFs must not incur an additional unbounded copy in Rust beyond the document's own decoded data. Canonical containment + symlink checks on every filesystem command (incl. `check_media_files_status`, currently unguarded); reject absolute paths and parent components. Protocol extension allowlist: `mp4, png, jpg, jpeg, webp, pdf, vtt`.

**Downloads.** HTTPS to `media.ehacademy.com` only; approved folder prefixes + approved root assets; extension allowlist `mp4, png, jpg, jpeg, pdf, vtt`. Never download `json`, `srt`, `md`, HTML, JavaScript, or SVG — the snapshot JSON is internal and not part of any media allowlist. Verify expected size always; compare the **HTTP response ETag against the manifest's opaque ETag for both single- and multipart objects**; local MD5 comparison optional and single-part-only. Connect + stall timeouts, capped retries, cancellation, resumable partials; none of it blocks playback or UI. `?v=<etag>` pinning retained (byte-zero rule on versioned downloads). Writes: temp file → flush → verify → atomic rename. Snapshot (`.content-versions.json`): same atomic pattern. Fix the `switchCourse` category ternary (`pediatric-cpr-aed` currently mis-buckets to `'first-aid'`).

**External links.** `tauri-plugin-opener` scoped to exact approved URLs (EH Academy, onboarding/hflip, mail, approved download page). Every subprocess spawn, `window.open`, and `_blank` anchor routes through the same helper; the raw `std::process::Command` `open_browser` is deleted.

**Fonts.** Inter, Playfair Display, JetBrains Mono bundled locally **with license files**; Google Fonts references removed from `src/index.css` + `splash.html`; fonts hosts removed from CSP.

**CSP.** `media:` token in img/media/connect-src; `https://media.ehacademy.com` in media-src; no fonts hosts; no `http://media.localhost` (Windows-only form).
